How the implied value is computed

Implied value = TVL × multiple. The multiple starts at 0.45× and moves with the snapshot's own figures: seven-day TVL change (clamped to −25%…+60%), how long the protocol has run with no token (+12% a year, up to five years), how many chains it runs on (+3% a chain, up to nine), and a small category weight (lending and exchange venues monetise TVL most directly; bridges and centralised venues are discounted). Before scoring, the house watchlist's exclusion rule applies as a filter: centralised exchanges, wrapped or staked products of a token that already trades, bridges and versioned copies never reach the board — the largest of them are listed under "set aside" with the reason, so the judgement is visible instead of silent. The result is clamped to 0.12×–1.60×. No protocol name is hardcoded: the same formula scores all 758 protocols, and the board ranks only the ones that record no token.

Implied value is this radar's claim, never a prediction. It does not say whether or when a token is issued. Farm plans are positioning for a launch that may never come: size every step as money you are fine losing.
